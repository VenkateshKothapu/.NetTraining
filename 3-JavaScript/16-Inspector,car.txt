(Imagine the browser is a road. Your code is a car driving smoothly.
 Now, we developers can place a red STOP sign using debugger;. 
 When the car (code) reaches this point, it stops. We can get out, open the engine (DevTools), and check everything — variables, speed, position.)

What is debugger;?

A tool that stops code execution for inspection.

Opens browser DevTools → Sources tab

Helps check variable values and program flow

When to use it?

When something’s going wrong and you want to check what's happening at a specific point.

When you want to learn how your program flows, step by step.

Debugging code techniques-
---------------------
debugger/Breakpoint:Pauses code execution at the specified point, allowing inspection in developer tools.

Resume(F8): Continue Running code until the next breakpoint

step Over(F10):Step over next line.

step into(F11):Step into the function call.

step out( shift + F11):Step out the current function and back to the callling function.

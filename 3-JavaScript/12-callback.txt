callback functions-
----------------------

A callback is a function you call back after something is finished

functions can accept other functions as parameters.which are called callback functions
these callbacks runs when the mainfunction has finished,giving you the ability to manage how the program proceeds

example of callback-
------------------------
Imagine you are building a LEGO house 🧱
When you're done building it, your mom says:

“When you're done, call me, and I will take a photo of your house.”

This Is a Callback!-

You build the house ➡️ This is the main task (main function).

Your mom takes a photo ➡️ This is the callback (something to do after you're done).

simple code-

function buildHouse(afterBuilding) {
  console.log(" Building the house...");
  afterBuilding(); // Call the other thing after you're done
}

function takePhoto() {
  console.log(" Taking a photo of the house!");
}

buildHouse(takePhoto);


example for callback-
---------------------
function messageone() {
    console.log("hey call me when you are done");
}

function messagetwo(info) {
    info();                         // ← runs messageone()
    console.log("this is message two");
}

messagetwo(messageone);
------------------------------------------------


Code Explanation (like a story)-

You created a function messageone()
→ It says: "hey call me when you are done"

Then you made another function messagetwo(info)
→ It says: “Run this function I got (info()), then print message two.”

You called messagetwo(messageone)
→ That means: pass messageone into messagetwo

So now:

info = messageone

info() becomes messageone()

Both messages print correctly

🔥 Summary:
messageone is passed into messagetwo
Inside messagetwo, it runs messageone()
Then prints its own line.

You just did a callback

What is Asynchronous?

In JavaScript:

Synchronous = tasks run one after another (wait for each other).

Asynchronous = tasks can start and finish later, without blocking others.

 So, when you call an API or set a timer (setTimeout), 
 it doesn’t block your code — it runs in the background.

What is a Callback?
A callback is just a function passed as an argument to another function — and it's called after a task is done.

"Call me back when you're done!"

-------------------------------------------------------------


Synchronous Example (no delay)

function taskOne() {
    console.log("Task 1 done");
}

function taskTwo() {
    console.log("Task 2 done");
}

taskOne();
taskTwo();

--------------------------------------------------
//Asynchronous with setTimeout (simulate delay)

function taskone(){
    setTimeout(function(){
        console.log("task one is done")
        
    },4000);
}

function tasktwo(){
    console.log("task two is done");
}

taskone();
tasktwo();

//output
// Task 2 done
// Task 1 done  ← (comes late after 2 seconds)
---------------------------------------------------------

Handle it using a callback-
--------------------
We will wait for Task 1 to finish and then run Task 2 — using a callback.



Making Tea (Callback Style)-
-----------------------------
function boilWater(nextStep) {
    setTimeout(() => {
        console.log("1. Boiling water...");
        nextStep();
    }, 2000);
}

function addTeaLeaves(finalStep) {
    setTimeout(() => {
        console.log("2. Adding tea leaves...");
        finalStep();
    }, 2000);
}

function serveTea() {
    console.log("3. Tea is ready. Enjoy!");
}

// Call in order using callbacks
boilWater(() => {
    addTeaLeaves(() => {
        serveTea();
    });
});


Output-
------
1. Boiling water...
2. Adding tea leaves...
3. Tea is ready. Enjoy!

Even with setTimeout (asynchronous delays),
the steps run in proper order because of callbacks.

KEY POINT:
Every function takes another function (callback) and calls it after the task finishes.

This is the classic way to handle asynchronous code in JavaScript.
--------------------------------------------------------------------


Warning: Callback Hell-
-----------

As you add more levels, your code can become deeply nested like this:

task1(() => {
    task2(() => {
        task3(() => {
            task4(() => {
                console.log("done!");
            });
        });
    });
});

This is called "callback hell", 
and later  learn how to fix it using Promises and async/await.
